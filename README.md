# HMM-project

## Overview

This project implements a **Hidden Markov Model (HMM)**, a statistical model used to describe the evolution of observable events that are influenced by internal, unobservable states. This implementation is designed for sequence analysis, such as predicting gene structures or pattern recognition in time-series data.

## Features

* **Forward-Backward Algorithm:** For calculating the likelihood of a sequence.
* **Viterbi Algorithm:** To find the most likely sequence of hidden states (the "optimal path").
* **Parameter Estimation:** Support for transition and emission probability matrices.
